# Reply Review

`address-review` でレビュー対応を行った後、各レビューコメントに返信する。

## 入力

- 引数なし: 直前の会話に含まれるレビュー対応サマリーと PR 情報を使う
- 数値のみ: PR 番号として解釈する
- `github.com` を含む URL: GitHub PR URL として解釈する

## 実行フロー

1. PR 番号を特定する
2. 直前の会話または入力からレビュー対応サマリーを取得する
3. `gh api` でレビューコメント一覧を取得する
4. 各コメントに対する返信文案を作る
5. 投稿前にユーザーへ文案一覧を示して承認を取る
6. 承認後に `gh api` で返信を投稿する

## 返信例

対応した指摘:

```text
修正しました。{修正内容の簡潔な説明}
```

対応しなかった指摘:

```text
確認しましたが、以下の理由により現状維持としました。

{理由}
```

## 注意事項

- 投稿前に必ずユーザー承認を取る
- 既に返信済みのコメントへ重複投稿しない
- 投稿にネットワーク権限が必要な場合は承認を取る
