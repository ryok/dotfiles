# シェルスクリプトを編集したら shellcheck を通す

編集したファイルに対して `shellcheck <path>` を実行し、警告が無いことを確認して
から完了とする。push してから CI に指摘されるのは遅い。

- 指摘を抑制する場合は `# shellcheck disable=SC####` を、**なぜ安全かの一文と
  セットで**書く。番号だけの抑制は後から判断できない
- shellcheck が未インストールなら、その旨を報告して完了扱いにしない
  (macOS: `brew install shellcheck`)

`set -e` の有無など、エラーハンドリングの方針はスクリプトごとに異なってよい。
ただし既定から外す場合は理由をコメントに残すこと。
